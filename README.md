# 🃏 FlashCards Inteligentes com IA 🤖

Este projeto foi desenvolvido com o objetivo de otimizar o processo de aprendizado dos usuários por meio de **flashcards** gerados dinamicamente com suporte à **inteligência artificial**. A plataforma permite criar flashcards personalizados com base nos assuntos e tópicos escolhidos, adaptando o conteúdo ao ritmo de estudo individual e facilitando a memorização de conceitos essenciais.

## 💡 Motivação

A ideia para este projeto surgiu ao identificar uma dificuldade pessoal: o tempo excessivo gasto na criação manual de flashcards. Com esta solução, o processo de estudo se torna mais eficiente, permitindo que os usuários concentrem seus esforços no aprendizado, sem a preocupação com tarefas manuais.
